# VK Audience Hunter

Локальное веб-приложение для поиска и аналитики открытых сообществ VK. Первая ниша — детские товары и одежда.

## Быстрый запуск на Windows

1. Установите **Python 3.11+** и **Node.js LTS**.
2. Скачайте репозиторий и распакуйте его.
3. Дважды щёлкните `start-local.bat`.
4. Откроется приложение: http://localhost:5173

При первом запуске скрипт создаст Python-окружение, установит зависимости, создаст файл `.env` из примера и установит frontend-пакеты. Оставьте оба открывшихся окна терминала работающими, пока пользуетесь приложением.

## Подключение VK API

1. Откройте файл `.env` в папке проекта.
2. Вставьте токен в строку `VK_ACCESS_TOKEN=` после знака равенства.
3. Сохраните файл и перезапустите backend (закройте и снова запустите `start-local.bat`).

**Не отправляйте токен в чат и не добавляйте его в GitHub.** Файл `.env` исключён из Git.

Если токен не задан, приложение показывает демонстрационные результаты. Это не реальные результаты VK.

## Где хранятся данные

История поисков и результаты сохраняются в локальной SQLite-базе:

`data/audience_hunter.db`

База создаётся автоматически при первом запуске. Её резервную копию можно сделать, скопировав файл базы при остановленном приложении.

Проверка backend: http://127.0.0.1:8000/api/health  
Документация API: http://127.0.0.1:8000/docs  
История запросов: http://127.0.0.1:8000/api/history

## Ручной запуск

Backend:
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Frontend — во втором окне терминала:
```powershell
npm install
npm run dev
```

## Архитектура и ограничения

- Frontend: React + TypeScript + Vite.
- Backend: Python + FastAPI.
- Хранилище: SQLite на ноутбуке, без облачного сервера.
- VK API token: только в локальном серверном файле `.env`.
- GitHub Pages остаётся вариантом публичной демонстрации интерфейса; для локальной работы запускайте frontend через Vite.

Приложение предназначено для поиска открытых сообществ, анализа агрегированных показателей и экспорта ID самих сообществ в CSV. Этот файл содержит идентификаторы групп, а не персональные ID их участников; он предназначен для организации исследований и настройки штатного таргетинга по сообществам в VK Рекламе.

Приложение не выполняет массовую выгрузку персональных ID участников чужих сообществ для рекламных баз. Публичность профиля сама по себе не означает согласие на такое использование. Для собственных клиентских списков используйте данные, полученные с надлежащим правовым основанием и в соответствии с правилами VK Рекламы. Сортировка участников по времени вступления через стандартный метод groups.getMembers доступна только при наличии необходимых прав модератора соответствующего сообщества; приложение не обходит это ограничение. Используйте VK API в соответствии с правилами платформы и применимым законодательством.

## Разработка и публикация

GitHub Actions продолжает собирать frontend для GitHub Pages. Backend не публикуется автоматически и при локальном использовании работает только на ноутбуке.
